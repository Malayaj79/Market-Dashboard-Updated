# Market Themes — MA Breadth Dashboard

A free, self-hosted dashboard that auto-refreshes daily with real data from Yahoo Finance. Shows exactly one thing: **what % of each theme's constituents are trading above their 10/21/50-day moving average** — no composite scoring, no resilience/emerging metrics.

**Live example:** https://clementang17-alt.github.io/market-dashboard/

## Features
- 52 catalyst-driven themes (cyclical/generic sector buckets removed — see below)
- % of constituents above 10/21/50-day MA per theme, plus raw "x/y" counts
- Sortable by any MA column
- Light-green→dark-green (50–100%) / yellow→red (50–0%) color gradient — no overbought/oversold labels
- SPY / QQQ / RSP shown as a pinned reference bar at the top (their own price vs. their own MA — not mixed into the theme rows). RSP is included because it's equal-weight, matching this dashboard's constituent-averaging approach
- Click ▸ on any theme to expand and see each constituent's individual MA status

## Setup (5 minutes)

### 1. Fork or create this repo on GitHub
Make sure it's **Public**.

### 2. Enable GitHub Pages
- Settings → Pages → Source: `main` branch, `/ (root)`
- Your site will be live at: `https://YOUR-USERNAME.github.io/REPO-NAME/`

### 3. Trigger first data fetch
- Go to **Actions** tab → **Refresh Market Data** → **Run workflow**
- This fetches real prices from Yahoo Finance and commits `data/market_data.json`

### 4. Done — auto-refreshes every weekday at 22:00 UTC (6pm ET)

## What got removed, and why
The previous version of this dashboard had a composite momentum score (return blend + relative strength + resilience + breadth), an "emerging theme" detector, a heatmap, sparklines, and a position-sizing calculator. All of that has been stripped out — this build does one job: MA breadth per theme, full stop. If you want any of that scoring machinery back, it existed and worked (see prior git history) — it just isn't part of this build.

## Theme list
The theme taxonomy was trimmed from an 81-section source list down to 52 by removing purely cyclical/generic sector buckets (oil, banks, retail, airlines, industrials, etc.) that don't have a specific, nameable catalyst — the working rule is "would this group's members reasonably move together on the same catalyst," not "do they share an industry classification." Five tickers intentionally appear in two themes each (SOUN, APLD, UPST, RMBS, COIN) where the company genuinely straddles two distinct catalysts — `fetch_data.py` logs this on each run as an informational note, not an error.

A handful of tickers (SATL, SIDU, YSS, FJET, INFQ, CBRS, FIGR, PURR, SHAZ, WYFI, BRUN, FRMI, KEEL, SWMR, ALMU, P, OPTX) are still pending a market-cap / dollar-volume liquidity check — they're live in the list for now.

## Note on a pre-existing bug (now fixed)
An earlier version of `index.html` had a corrupted template literal (escaped backticks) that threw a JS syntax error and silently broke the *entire* inline script — meaning nothing on the page was rendering. That bug doesn't exist in this rewritten version, since the emerging-score code it lived in has been removed entirely along with everything else in that cleanup.

## Updating MA Signals
Open `fetch_data.py` and update the `ma` values in the `THEMES` list:
- `+1` = Bullish (ETF above 50-day MA)
- `0`  = Neutral
- `-1` = Bearish

Then push — the next Action run will use the new signals.

## Momentum Score Formula
```
Score = (ReturnBlend × 45%) + (RSBlend × 35%) + (MA_signal × 7pts)
ReturnBlend = 1D×20% + 1W×35% + 1M×45%
RSBlend     = same weights on Relative Strength vs SPY
```
